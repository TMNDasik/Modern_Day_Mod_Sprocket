## О моде

**Modern Day Mod** - масштабная модификация для **Sprocket**, посвящённая современной бронетехнике.

Мод добавляет современные системы техники, вооружение, боеприпасы, средства защиты, новые механики силовых установок, визуальные эффекты, звуки и улучшения удобства игры.

Наша цель - дать игрокам больше свободы при создании современной бронетехники, а также сделать её поведение и боевое применение более разнообразными.

> [!IMPORTANT]
> Modern Day Mod находится в активной разработке. В будущих обновлениях отдельные функции могут меняться, перерабатываться, временно отключаться или заменяться.

> [!WARNING]
> **Игра вылетает при загрузке главного меню?**
>
> Установите `SprocketInteropFix.dll` в папку:
>
> ```text
> Sprocket/BepInEx/patchers
> ```

## Установка

### Требования

Для Modern Day Mod требуется **BepInEx Unity IL2CPP x64**.

Рекомендуемая сборка:

**BepInEx 6.0.0-be.788**

https://builds.bepinex.dev/projects/bepinex_be/788/BepInEx-Unity.IL2CPP-win-x64-6.0.0-be.788%2B5b766a3.zip

> [!NOTE]
> Рекомендуется использовать именно эту сборку BepInEx: мод разрабатывается и тестируется с ней.

### 1. Установка BepInEx

1. Скачайте сборку BepInEx по ссылке выше.
2. Откройте папку установки Sprocket через Steam:
   **Sprocket -> Свойства -> Установленные файлы -> Обзор**
3. Распакуйте все файлы из архива BepInEx в корневую папку Sprocket.
4. Запустите Sprocket и дождитесь главного меню.
5. Закройте игру.

При первом запуске BepInEx автоматически создаст необходимые папки и файлы.

### 2. Установка Modern Day Mod

Поместите файлы Modern Day Mod в папку:

```text
Sprocket/BepInEx/plugins
```

После этого запустите Sprocket обычным способом.

При правильной установке Modern Day Mod должен автоматически загрузиться через BepInEx.

## Совместимость

> [!CAUTION]
> **Modern Day Mod в настоящее время несовместим с модом Cold War.**

Одновременная установка этих модов может вызывать ошибки, нарушения работы функций или вылеты игры.

Совместимость с другими модами не гарантируется. При сообщении об ошибках обязательно указывайте все установленные дополнительные моды.

---

## Решение проблем

Прежде чем сообщать о проблеме, проверьте, что:

- BepInEx установлен правильно
- Используется рекомендуемая сборка BepInEx
- После установки BepInEx вы хотя бы раз запускали Sprocket
- Файлы Modern Day Mod находятся в `BepInEx/plugins`
- Старые файлы предыдущих версий Modern Day Mod удалены
- Текущая версия Sprocket совместима с модом
- Конфликтующие модификации отключены

Если игра вылетает при загрузке главного меню, установите:

```text
SprocketInteropFix.dll
```

в папку:

```text
Sprocket/BepInEx/patchers
```

### Проблемы после обновления?

Перед установкой новой версии полностью удалите предыдущую версию Modern Day Mod.

Оставшиеся DLL-файлы и другие старые файлы могут вызывать непредсказуемые ошибки.

## Сообщения об ошибках

Нашли баг?

Сообщите о нём в **разделе обсуждения модов официального Discord-сервера Sprocket** и отметьте:

**@TMNDas1**

Полезный баг-репорт должен содержать:

- Понятное описание проблемы
- Ваши действия перед её появлением
- Шаги для воспроизведения
- Информацию о том, возникает ли ошибка постоянно
- Версию Sprocket
- Список других установленных модов
- Логи консоли BepInEx
- Скриншоты или видео, если возможно

По сообщениям вроде *«не работает»* без логов и подробностей крайне сложно понять причину проблемы.

Чем подробнее отчёт, тем проще воспроизвести и исправить ошибку.
